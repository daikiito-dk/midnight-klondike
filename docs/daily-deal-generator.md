# Daily Deal Generator

The Daily Deal generator converts the deterministic 52-card deck into the standard Klondike opening layout.

- 7 tableau columns containing 1–7 cards.
- Only the top card in each column starts face up.
- The remaining 24 cards form the stock.
- The same date always produces the same deal when the same rules are used.
- Classic mode remains unchanged; integration into the main game flow is a later step.
